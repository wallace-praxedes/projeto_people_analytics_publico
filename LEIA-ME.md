# PROJETO DE PEOPLE ANALYTICS

## 1. OBJETIVO DO PROJETO

Esse projeto tem como finalidade expor o meu conhecimento técnico, resoluções de principais demandas da área de Recursos Humanos por meio da análise de dados e ser referência para empresas neste tema de Análise de Dados de Pessoas.

## 2. INFORMAÇÕES GERAIS

Esse projeto parte do meu conhecimento profissional e acadêmico. Todas as informações usadas para a criação do Projeto foram criadas aleatoriamente a partir do que vi ao longos desses anos em Recursos Humanos. Reforço que todos os dados usados são fictícios, não infrigindo qualquer dado sensível ou sigiloso de terceiros.

## 3. ESTRUTURA DO PROJETO

Esse projeto tem a seguinte estrutura:

- **Pessoas:** Aqui o projeto atenderá à parte de pessoas, ou seja, indicadores de sexo, idade, tempo de casa, estrutura organizacional e etc.
- **Custo:** Aqui o projeto atenderá à parte de custo de pessoas, ou seja, indicadores de salário, custo dos benefícios ao longo dos meses, encargos, criação de orçamento e etc.
- **Rotatividade:** Aqui o projeto atenderá à parte de desligamentos e contratações, ou seja, o turnover, quem mais sai da empresa, qual o grupo mais suscetível para sair, savings e etc.
